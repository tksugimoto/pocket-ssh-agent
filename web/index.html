ペアリングした PC は、あなたが承認すればこの鍵で GitHub などにログインできるようになります。自分の PC でなければ「やめる」を押してください。

  2. 表示された QR コードを、下のボタンから読み取ります。

ペアリング先:

承認待ちのリクエストはありません

PC で git push や ssh を実行すると、ここに表示されます。
承認するにはこの画面を開いたままにしてください。

ホーム画面に追加してから使ってください。

iPhone では Safari とホーム画面のアプリで保存領域が別々です。Safari のままペアリングすると、ホーム画面のアプリからは鍵が見えません。また Safari の保存データは、しばらく開かないと消えることがあります。

共有ボタン →「ホーム画面に追加」→ 追加したアプリを開き、アプリ内で QR コードを読み取ってください。
